# Politique de confidentialité

Sieve of Eratosthenes respecte votre vie privée.

## Principes

* **Traitement local** : Tous les calculs de nombres premiers s'exécutent
  entièrement sur votre appareil.

* **Aucun compte requis** : L'utilisation du jeu ne nécessite aucune
  inscription.

* **Aucun suivi** : Aucune donnée d'identification personnelle n'est
  collectée.
