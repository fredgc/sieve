O **Crivo de Eratóstenes** é um jogo educativo matemático interativo e uma
demonstração rítmica projetada para transformar a teoria dos números e a
descoberta de números primos em uma experiência audiovisual envolvente.

## História e Motivação

Criado no século III a.C. pelo matemático grego e bibliotecário-chefe de
Alexandria **Eratóstenes de Cirene** (c. 276–c. 195 a.C.), o Crivo é um dos
algoritmos mais intuitivos da matemática para encontrar todos os números
primos.

Para contexto histórico e teoria algorítmica, leia o
[artigo da Wikipédia sobre o Crivo de Eratóstenes][wiki].

## Analogia Audiovisual

Para explorar como números primos recebem tons harmônicos atômicos e números
compostos formam acordes musicais, consulte a
[Analogia Audiovisual](analogy.html).

Este aplicativo foi desenvolvido em Dart com Flutter—o código-fonte está
disponível no GitHub em [https://github.com/fredgc/sieve][github].

## Privacidade e Retenção de Dados

Este programa permite personalizar configurações que são salvas localmente no
seu dispositivo (utilizando SharedPreferences / LocalStorage). Nenhum dado
pessoal é coletado.

No Android, as configurações locais são excluídas ao desinstalar o aplicativo.
Na Web, as configurações são excluídas ao limpar os dados locais de navegação
do aplicativo.
