Sieve of Eratosthenes (v3.0.3+0)

An interactive, educational rhythm game and audio-visual mathematical demonstration of the Sieve of Eratosthenes, built with Flutter for Web and Android.

1. Project Overview & Motivation

The Sieve of Eratosthenes is an ancient algorithm dating back to the 3rd century BCE, formulated by Greek mathematician and chief librarian of Alexandria Eratosthenes of Cyrene. It is one of the most elegant and efficient algorithms for finding all prime numbers up to any limit by systematically marking multiples of each discovered prime as composite.

This project transforms the algorithm into a living, rhythmic, audio-visual experience and number-reflex game: * The Sieve Rhythm Clock: The app counts forward at an adjustable tempo (default: 1.0 Hz=60 BPM1.0\text{ Hz} = 60\text{ BPM}). * Atomic Prime Tones: Each discovered prime is assigned an atomic musical tone derived from the natural overtone series (2=C3,3=G3,5=E4,7=B4♭,11=F5♯,13=A52 = C_3, 3 = G_3, 5 = E_4, 7 = B^\flat_4, 11 = F^\sharp_5, 13 = A_5). * Composite Harmonic Chords: When the rhythm reaches a composite number NN, it sounds all of its prime factors simultaneously as a musical chord (e.g. 6=2×36 = 2 \times 3 plays an open fifth chord C−GC - G; 30=2×3×530 = 2 \times 3 \times 5 resolves into a complete C Major triad C−E−GC - E - G). * Prime Multiplicities (Powers) as Octaves: Numbers with repeated factors (4=22,8=23,12=22×34 = 2^2, 8 = 2^3, 12 = 2^2 \times 3) layer higher octave harmonics, enriching the timbre. * Continuous Proximity Waves: The bottom dashboard displays real-time progress bars for each discovered prime using the continuous triangle wave metric: f(t)=|2⋅((speed⋅t)(mod⁡p))p−1.0|f(t) = \left| 2 \cdot \frac{((\text{speed} \cdot t) \pmod p)}{p} - 1.0 \right| smoothly peaking at 1.01.0 exactly at multiples of pp and falling to 0.00.0 at midpoints.

4. Development & Running

Starting Development Environment

./setup.sh

Running Locally

# Debug mode on local port
./run-local-server.sh

# Or release build local server
./run-local-release.sh

Building Assets & Documentation

make ASSETS

Running Tests

flutter test
flutter analyze

Staging to Firebase Hosting

make stage

Deploy the app to the staging channel on Firebase Hosting for project fredgc-sieve.
